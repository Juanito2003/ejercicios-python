# Ejercicios de Python

Scripts cortos de Python hechos como prácticas.

| Script | Qué hace |
|---|---|
| `tarea2.py` | Pasa un número decimal a binario dividiendo entre 2 |
| `tarea2_1.py` | Pasa un número binario a decimal y muestra el peso de cada dígito |
| `info_procesador.py` | Muestra el procesador del equipo con `platform` |
| `uso_memoria.py` | Mide la memoria que usa un bucle con `tracemalloc` |

## Uso

Necesitan Python 3. No hay dependencias externas.

```bash
python3 tarea2.py      # escribe un número, por ejemplo 6 → 110
python3 tarea2_1.py    # escribe un binario, por ejemplo 1101 → 13
python3 info_procesador.py
python3 uso_memoria.py
```
